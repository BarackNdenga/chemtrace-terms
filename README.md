# ChemTrace — Conditions d’utilisation

Site statique HTML pour l’application Android ChemTrace (`com.chemtrace.app`). Il comprend les Conditions d’utilisation en français et la politique de confidentialité existante, reproduite en anglais. Aucun framework, serveur, gestionnaire de paquets ou processus de compilation n’est nécessaire.

## Fichiers

- `index.html` — Conditions d’utilisation en français, avec table des matières navigable.
- `politique-confidentialite.html` — texte existant de la politique, reproduit en anglais.
- `styles.css` — styles responsives utilisant les polices système.
- `manus-routes.json` — manifeste des routes pour l’aperçu de développement.
